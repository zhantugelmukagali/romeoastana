# БонусПро

Расширение МойСклад для бонусной программы: целевой сценарий — виджет в заказе
покупателя и административная панель. Apple/Google Wallet отложены.

## Текущее состояние

Реализованы серверное финансовое ядро, авторизация установки и сотрудников,
обработка отмены начислений без долга, очередь заданий и экран разбора возвратов.
Собирается контейнер с отдельной PostgreSQL; исходники — в bonuspro/rebuild, PR #1.

Добавлен виджет заказа: сохранённые данные REMAP, резерв, изменение скидки в форме
и списание после серверной проверки сохранённого документа и метки операции.
Основной набор из 169 тестов проходит, включая PostgreSQL и Chromium.

**Это ещё не готовая замена БонусПлюс.** Автоматические начисления/сверка и полный
цикл возвратов не подключены. Нужны допуск обычных сотрудников, расширение поддерживаемых
случаев расчёта и настоящая приёмка МойСклад. Рабочая активация пока заблокирована.
На VPS запущена предыдущая основа (схема 0005). Части 1–2 со схемой 0007 проверены
в CI, но ещё не выложены на VPS. База пилота не перенесена.

## Утверждённые правила

- Начисление 5% от допустимой суммы до бонусного списания, предел списания 30%.
- Проценты настраиваются с историей изменений; 1 бонус = 1 ₸, целые бонусы с округлением вниз.
- Начисление только после полной оплаты И полной отгрузки; бонусы бессрочные.
- Только товары; доставка исключается из начисления и списания.
- Старые продажи автоматически не начисляются.
- Если при возврате не хватает бонусов для отмены начисления, решает администратор.
  Автоматического отрицательного баланса нет.

## Проверка

Финансовые unit-тесты без внешних сервисов:
```sh
PYTHONPATH=backend python3 -m unittest discover -s tests/unit -v
```

Полный GitHub Actions workflow проверяет настоящую PostgreSQL, RLS, конкурентные
операции, авторизацию, HTTP API и браузерные сценарии. Отдельно запускаются
контейнер, миграции, восстановление тестовой БД и аудит зависимостей.
Синтетические credentials в CI относятся только к временным базам.

## Сохранность

Код и миграции сохраняются в GitHub. База, ключи и резервные копии — отдельно.
Смена ноутбука не удалит удалённый репозиторий или VPS. Git не заменяет backup БД.
Секреты нельзя коммитить; deploy/secrets исключён из Git и Docker context.

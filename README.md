# БонусПро

Расширение МойСклад: бонусы в заказе покупателя, связанные оплаты, отгрузки и возвраты.
Apple/Google Wallet отложены. Рабочие документы остаются в МойСклад, бонусный журнал — в PostgreSQL.

## Реализация

- Настройки процентов с неизменяемой историей; доставка и услуги исключены.
- Виджет: баланс, лимит, резерв, изменение скидки в форме МойСклад, списание только после серверной проверки сохранённого документа.
- Фоновое начисление после полной оплаты **и** полной отгрузки; повторные задания не дублируют деньги.
- Частичные/полные возвраты, их исправление и отмена, возврат списанных бонусов и пересчёт начисления.
- Недостаток бонусов передаётся администратору; отрицательный баланс автоматически не создаётся.
- Перенос сопоставленных CSV-остатков: проверка, отдельное подтверждение, атомарность, защита от повторного клиента.
- Активация с подтверждением статуса Vendor API и неизменной датой начала программы.
- Явные разрешения сотрудников; отзыв проверяется перед финансовой транзакцией.
- Аудированный разбор отменённого неприменённого списания; диагностика задержек и расхождений.
- Durable webhook inbox, инкрементальные updated-потоки, повторный поиск поздно появившихся заказов.
- Приоритет текущих изменений, ограниченные batch, редкая сверка старой истории и очистка технических очередей.
- Шифрованные checkpoint, отдельная проверка восстановления, шаблон локального таймера.

Код: ветка `bonuspro/rebuild`, [draft PR #1](https://github.com/zhantugelmukagali/romeoastana/pull/1).
Схема: **0015**. [Проверки и реальные ограничения](docs/IMPLEMENTATION.md).
По последнему выводу владельца VPS обновлён до 8a55609 / схемы 0013, HTTPS работает.
Изменения 0015 ещё не развёрнуты, worker не запущен. Настоящая установка/продажа не приняты.
Готовность к замене БонусПлюс не заявляется до приёмки.
Для нескольких магазинов добавлен автоматический пул активированных аккаунтов; его нужно запустить и проверить на VPS.

## Правила

1 бонус = 1 ₸; целые бонусы вниз; бессрочные. Начальные ставки 5%/30% настраиваются.
База начисления — участвующие товары после обычных скидок, до бонусного списания.
Правила закрепляются при первом подключении заказа. Старые покупки не начисляются автоматически.

## Проверка и сохранность

GitHub Actions выполняет unit/contract-тесты, PostgreSQL integration, Chromium,
миграции, контейнерный запуск, тестовое восстановление pg_dump/pg_restore и pip-audit.
Имитация host в браузерных тестах не заменяет настоящую установку МойСклад.

Код хранится в GitHub. База, секреты и резервные копии хранятся отдельно.
Смена ноутбука не удаляет репозиторий или VPS; Git не является резервной копией БД.

# Интерфейс кабинета

Правила, подключение и история разделены на вкладки. На вкладке правил остаются две ставки, обязательная причина изменения и сохранение. Калькулятор показывает начисление и лимит по сумме товаров; расчёт выполняется локально и не создаёт финансовой операции. При изменении правил старые заказы сохраняют свою версию.

В кабинете убраны декоративные значки показателей и пустые растянутые карточки. Общие CSS-правила собраны в один слой без накопления несовместимых переопределений. На узкой ширине карточка клиента сохраняет баланс и доступную сумму с подписями. История возвратов остаётся доступной из сверки.

Протокол МойСклад, авторизация, денежные операции и серверные лимиты не изменены. Вкладки поддерживают стрелки/Home/End. Внутренняя прокрутка работает при отключённой прокрутке iframe хостом.

Chromium проверяет ширины 320–1920px для кабинета, 320–760px для виджета, длинные имена и суммы, сохранение правил, предварительный расчёт, переходы и фокус. Скриншоты правил и виджета сохраняются в артефакт bonuspro-interface. Данные браузерных проверок изолированы от рабочей базы.

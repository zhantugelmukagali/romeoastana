# Исправление подключения виджета

Официальная коллекция дополнительных полей REMAP содержит meta.href/mediaType и rows без обязательного meta.size. Прежняя проверка размера ошибочно отвергала такой полный ответ. Создание поля использует документированный массив из одного элемента; ответ нормализуется только для фиксированного endpoint метаданных.

Источник контракта: https://dev.moysklad.ru/doc/api/remap/1.2/ — «Получить все дополнительные поля для указанного типа» и «Создать дополнительные поля».

Сохранены ограничения полноты, типа, UUID, адреса поля и принадлежности аккаунту. Параллельное создание сериализуется session advisory lock без открытой финансовой транзакции на время сетевых запросов. Повтор после потерянного ответа находит уже созданное поле. Если ранее привязанное поле удалено, новое не создаётся автоматически.

Ошибки прав, отклонённого токена, временной недоступности, несовместимых метаданных и изменённой привязки отображаются отдельно. Токены и содержимое ответов провайдера не выводятся пользователю. Настройка поля не активирует продажи и не меняет бонусы.

Обновление совместимой ветки не требует миграций или замены секретов. Если прав useOwnAttributeMetadata ещё нет в установленной конфигурации, требуется обновить дескриптор и установленное решение.

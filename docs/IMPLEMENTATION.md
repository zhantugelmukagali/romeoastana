# Состояние реализации
Дата начала новой реализации: 2026-10-13.

Начальный код находится в ветке bonuspro/rebuild и draft PR #1. В main пока документация.
Запуски GitHub Actions на момент проверки не обнаружены; тесты НЕ подтверждены.

## Сохранено в GitHub
- Целевая архитектура и критерии приёмки.
- Изолированная целочисленная финансовая арифметика: расчёт, предел списания, распределение по строкам, дельта совокупного начисления.
- Unit-тесты и детерминированные проверки инвариантов.
- Workflow для GitHub Actions. Наличие файла workflow само по себе не означает успешный запуск.

## Не реализовано
PostgreSQL schema и транзакции, журнал, резервы, очередь и saga, Vendor lifecycle, REMAP adapter,
widget bridge, API авторизация, интерфейс, импорт, production deployment и мониторинг.
Функция quote — предварительный расчёт, не разрешение на списание.
Функция earned_points не проверяет оплату/отгрузку: это обязанность будущего application-сценария.

## Проверки доступа
GitHub: подтверждены чтение, запись и удалённые коммиты.
Среда исполнения чата: environment_startup_failed, shell/SSH отсутствуют.
Домен: веб-инструмент не смог открыть сайт; доступность и TLS этой попыткой не установлены.
Сервер/БД: имеются пользовательские результаты docker ps; независимая текущая SSH-проверка не выполнена.
Код и финансовые данные существующего VPS не изменялись.
Полноценная проверка запуска и реальные сценарии МойСклад остаются обязательными.

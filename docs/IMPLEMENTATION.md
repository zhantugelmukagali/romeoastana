## Реализовано

- Целочисленные расчёты, лимиты, распределение скидки.
- PostgreSQL: FORCE RLS, составные FK, неизменяемый сбалансированный журнал.
- Идемпотентные зачисления/резервы; блокировки кошелька; списание по внутреннему
  контракту подтверждённой скидки. Неизвестный внешний результат сохраняет резерв.
- Vendor lifecycle Install/Resume/Suspend/Uninstall: JWT HS256, jti против replay,
  шифрование REMAP token AES-GCM с привязкой к tenant, поколение установки.
- Одноразовый user context меняется на сервере на собственную сессию; роли сотрудника
  подтверждает Vendor API. Suspend/Uninstall отзывают сессии.
- Отмена начисления по UUID возврата: проводка либо дело администратора без долга.
  Pending блокирует новые резервы; решение администратора сохраняет причину и автора.
- Экран возвратов: белый интерфейс, состояния/история, подтверждение, обязательная
  причина, блокировка недоступного списания, ошибки, повтор, пагинация, мобильная ширина.
- PostgreSQL jobs: транзакционная постановка/подтверждение, SKIP LOCKED,
  аренда с fencing token, повтор с задержкой, предел попыток, dead.
- HTTP: проверка Origin/Host, ограничение тела, CSP, no-store, скрытие секретов
  из ошибок; административный API не принимает роль, автора или сумму из браузера.
- Контейнер non-root/read-only, явные миграции отдельной ролью, файловые секреты.
- CI: функциональные, конкурентные, HTTP, браузерные тесты, контейнерный запуск,
  восстановление БД, lock-файл и pip-audit.

## Что блокирует выпуск

Это существенная недостающая реализация, а не только ожидание доступа:

1. REMAP-адаптер документов и проверенное применение скидки через виджет заказа.
   VerifiedDiscount пока внутренний объект, а не результат готового адаптера.
2. Связи клиентов/заказов, версии правил, исключения товаров/доставки,
   перерасчёт оплат/отгрузок/возвратов/отмен по актуальным документам.
3. Worker/планировщик, приём событий и сквозное восстановление потерянного ответа.
   Компонент jobs сам по себе не синхронизирует МойСклад.
4. Возврат ранее списанных бонусов по строкам, изменение/отмена документа возврата,
   восстановление актуального начисления после исправления документов.
5. Настройка магазина и переход SettingsRequired -> Activated. Сейчас установка
   намеренно не объявляется активированной до реализации конфигурации.
6. Полный виджет продажи, импорт остатков БонусПлюс с dry-run и сверкой.
7. Подтверждённые appId/appUid, настройка Secret Key вне чата, окончательный descriptor
   и настоящая установка/приёмка в отдельном аккаунте МойСклад.
8. Ограничение частоты запросов и квот API, мониторинг/оповещения, очистка истёкших
   сессий/replay, ротация ключей, независимый backup VPS и репетиция переключения.
9. Проверка нагрузки на VPS 2 GB и подготовка эксплуатационной поддержки.

Wallet не включён в первый выпуск по решению владельца.

# Утверждённое правило возвратов
2026-10-13: владелец отклонил автоматический отрицательный бонусный баланс.

Если при отмене начисления после возврата клиент уже потратил эти бонусы,
случай должен быть передан администратору. Нельзя молча обнулить баланс, простить разницу,
создать долг или увеличить денежный возврат на сумму бонусов.
На время разбора предлагается блокировать новые списания клиента; это было сообщено владельцу при фиксации ответа.
Точная транзакционная реализация и интерфейс разбора ещё должны пройти тесты.

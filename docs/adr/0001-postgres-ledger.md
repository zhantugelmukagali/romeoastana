# ADR 0001: явный SQL для финансового журнала
Статус: принято для реализации.

Финансовые транзакции используют psycopg 3 и параметризованный SQL.
Явные SELECT FOR UPDATE, порядок блокировок и SET LOCAL tenant context проще проверять,
чем скрывать эти операции за ORM. SQLAlchemy используется инфраструктурой миграций Alembic.
Это уточняет первоначальное предложение SQLAlchemy ORM; бизнес-инварианты не меняются.

Изменения ledger запрещены триггерами и правами. Проверка сбалансированности отложена до commit,
чтобы обе проводки и состояние резерва записывались атомарно.
Приложение подключается отдельной LOGIN ролью, наследующей bonuspro_app, без BYPASSRLS и superuser.
Привилегированный bootstrap создаёт групповую роль до миграции; создание пользователей и паролей не входит в прикладной код.
Рабочий deployment и управление credentials будут оформлены отдельно, CI provisioning не предназначен для VPS.
